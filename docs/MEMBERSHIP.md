# 账号、卡密及次数额度

## 部署配置

复制 `.env.example` 为 `.env`，配置 PostgreSQL、Better Auth 的公开 URL 与至少 32 字符随机密钥、SMTP、私有 S3 桶和另一份至少 32 字符的卡密摘要密钥。卡密摘要密钥应持久保管，改动会导致此前卡密无法兑换。对象存储凭证只保存在服务端，不配置公共读权限。邮件发送失败会使注册验证不可用，不提供绕过验证的生产开关。

部署环境初始化需要安装依赖、生成 Prisma 客户端及执行数据库迁移：`npm install --ignore-scripts`、`npm run db:generate`、`npm run db:deploy`。这些是部署准备步骤，本次实现未自动执行代码生成、迁移、构建或启动服务。执行脚本时须由运行环境注入 `.env` 变量，例如 Node 20+ 使用 `node --env-file=.env scripts/grant-admin.mjs user@example.com`。

管理员先通过网页注册并验证邮箱，再由部署者运行 `admin:grant` 指定邮箱。网站不允许用户自行指定角色。Linux 环境需要可用的中文字体，设置 `EXPORT_FONT_PATH` 指向 Noto Sans CJK 字体文件。导出上限为 200 × 200 格，每格 30 像素；服务端需预留约 300 MB 图像处理内存，平台请求超时至少 120 秒。

上线前将 `NEXT_PUBLIC_SOURCE_URL` 配置为当前部署版本的完整修改源码地址。保留上游 LICENSE 和版权；只提供上游仓库链接不足以提供本版本源码。

## 业务规则

游客可生成预览与编辑；正式 PNG/CSV 导出须登录并验证邮箱。次数长期有效，卡密有独立兑换截止时间。每次成品包含图纸和采购清单；CSV 可选，是否包含 CSV 是导出设置的一部分。同一账号、规范化网格、品牌及全部设置对应唯一任务，成功任务重新下载免费。不同账号不共享任务。客户端的色号和统计不可信，服务端依据原项目色板重算。

首次导出预占 1 次，渲染与上传成功后事务提交扣费。普通失败释放预占；进程崩溃、请求强制终止需恢复任务。部署者每分钟调用 `exports:recover`，或在管理后台恢复超过 10 分钟未完成的任务。恢复与完成通过状态、尝试标识及数据库事务互斥，迟到任务不能扣费。对象存储成功但数据库失败可能留下未关联文件，建议周期性检查并清理无数据库成功任务引用的对象，不能按文件年龄删除成功任务文件。

桶中成功文件需长期保留；下载链接有效 5 分钟，个人中心重新签名不扣费。不设置删除全部导出文件的生命周期规则。并发导出、兑换及人工调账使用 PostgreSQL Serializable 事务、用户行锁和唯一约束；余额包含预占额度，可用次数为 balance − reserved。人工扣减不得动用预占额度。

管理后台可生成最多 500 张卡，明文仅在生成响应中返回，保存摘要和尾号。页面清除或刷新后无法再次获取明文。禁止记录请求体、卡密或邮件验证链接。制卡响应丢失不能恢复明文，可按批次定位未使用卡密并逐张禁用，再生成新批次。

## 接口及验证

- `/api/auth/*`：Better Auth 邮箱注册、登录、验证、重置密码和会话。
- `GET /api/me`：余额、最近 50 条兑换、额度流水及导出任务。
- `POST /api/credits/redeem`：`{ code }`，每账号每分钟最多 5 次尝试。
- `POST /api/exports`：原编辑器网格、尺寸、品牌、设置；最多 4 MB，每账号每分钟最多 10 次。
- `GET /api/exports/:id`：账号自己的成功任务下载链接。
- `/api/admin`：管理员查询用户/卡密/流水/审计及制卡、禁用、调账、封禁、任务恢复。列表每页 50 条。

写入业务接口校验 Origin，认证库校验自己的 CSRF；数据库限流适用于多进程部署。PWA 不缓存私人页面或 API。升级已有 PWA 时检查旧 Service Worker 是否仍控制页面，必须验证用户切换后看不到前一账号数据。

运行 `npm run test:membership` 验证规范化、卡密摘要、额度预占、重复导出、失败释放、恢复与重试边界；这是直接执行 JavaScript 的测试，不编译项目。仅在独立测试数据库迁移完成后设置 PERLER_INTEGRATION_DATABASE_URL（不要指向生产库），再运行 `node --env-file=.env --test tests/postgres.integration.mjs` 进行真实并发事务测试。上线验收还需通过现有应用验证邮件全流程、两个账号隔离、管理权限、移动端导出及 PNG 的中文/色号/数量；不要用编译成功替代这些验证。

监控数据库事务失败、任务超时数量、邮件失败、存储错误及余额流水不一致；数据库与私有对象存储分别备份。本站提供在线导出服务，无法阻止用户截图或运行开源项目。
